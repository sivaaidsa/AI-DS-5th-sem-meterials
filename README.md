# EGS Pillay Engineering College – AI & DS Course Materials

A responsive static website for third-year B.Tech Artificial Intelligence & Data Science course materials.

## Files
- `index.html` — complete website (HTML + CSS; no extra dependencies).

## Publish using GitHub Pages
1. Sign in to https://github.com/
2. Click **New repository**.
3. Enter a repository name, for example `ai-ds-course-materials`.
4. Choose **Public**, then click **Create repository**.
5. On the repository page, click **Add file → Upload files**.
6. Upload `index.html` (you can also upload this README).
7. Click **Commit changes**.
8. Open **Settings → Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Select branch **main** and folder **/(root)**, then click **Save**.
11. Wait a few minutes. GitHub will show your website URL, usually:
    `https://YOUR-GITHUB-USERNAME.github.io/ai-ds-course-materials/`

## Important
- Keep the file name exactly `index.html` and place it in the repository root.
- The Google Drive links are embedded behind the four course cards.
- Make sure the Google Doc / Drive folders have suitable sharing permissions (for example, anyone with the link can view, if appropriate). Do not make private class materials public unless you have permission.
- To update the site later, edit `index.html` in GitHub and commit the changes.
